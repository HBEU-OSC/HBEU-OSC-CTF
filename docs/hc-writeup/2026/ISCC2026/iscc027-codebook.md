# 密码本查表

> 比赛：ISCC 2026　方向：Crypto　作者：杨心凌
>
> 仅在赛事授权的题目环境中复现。

## 题目信息

- **题目描述：** 截获一份用“密码本”加密的报文。密码本的每一页是一个表格，每个单元格填写一个英文单词；密文由若干组 4 位数字组成，编码规则为 `P-HH-C`，即第 P 页、第 HH 行、第 C 列。
- **附件与素材：** 密码本以图片/表格形式给出（原稿未随文保留）。题目示例：`5278` 表示第 5 页第 27 行第 8 列。
- **密文：** `2021，5129，3158，0254，6190`
- **关键线索：** 示例直接给出了 4 位数字的拆位方式，需要按“页-行-列”顺序拆分并查表。

## 解题思路

1. 按示例把每组 4 位数字拆成 `P | HH | C`：第一位为页号、中间两位为行号、最后一位为列号。
2. 在密码本对应页的表格中定位行、列，取出单元格里的英文单词。
3. 按密文顺序把单词连成句子，检查语义是否通顺；若不通顺，回看行列是否从 0 开始计数、页号是否含封面页等细节。
4. 得到完整明文后提交。

## 分析与复现

### 第一步：拆码

| 密文 | 页 P | 行 HH | 列 C |
| --- | --- | --- | --- |
| 2021 | 2 | 02 | 1 |
| 5129 | 5 | 12 | 9 |
| 3158 | 3 | 15 | 8 |
| 0254 | 0 | 25 | 4 |
| 6190 | 6 | 19 | 0 |

> 说明：原稿只保留了示例 `5278 → 第 5 页第 27 行第 8 列` 与上述密文，密码本图片未随稿保存，因此本文不展示逐码查表得到的词；实际解题时以题目给出的密码本为准。

### 第二步：查表拼句

在密码本中逐一定位并抄写单词，按顺序拼接，得到一句语义完整的英文报文，提交即可。

## 核心代码

本题以人工查表为主。若把密码本整理成嵌套字典/二维数组，可批量查询：

```python
def lookup(code: str, book: dict) -> str:
    page, row, col = code[0], int(code[1:3]), int(code[3])
    return book[page][row][col]

codes = ["2021", "5129", "3158", "0254", "6190"]
# book 需按题目密码本录入，例如 book["5"][27][8] -> 单词

```

## 结果验证

按密码本逐码取词并拼句后，得到通顺的英文报文；提交后平台判定正确。

## 复盘与经验

- **关键知识点：** 定长编码的拆位规则；密码本（codebook）的定位方式。
- **容易踩的坑：** 行号/列号从 0 还是从 1 开始；页号是否包含封面；4 位码中“行号固定两位”容易被忽略。
- **后续改进：** 一次性密码本体系的关键是密钥本保密且不复用；实际系统应使用现代认证加密而非手工查表。
